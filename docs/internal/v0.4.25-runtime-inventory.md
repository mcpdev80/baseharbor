`EnsureFilesForProjectAndResources` has one production direct caller:
`cmd/baha/target.go:ensureTargetRuntimeFiles`. The `EnsureFiles*` wrappers and
explicit management installation consume this stack. Test direct callers live
in runtime, application shared-Core-SQL and identityprovider tests. Keep its
SQL/OpenBao provisioning intact; bypass its callers for derived local
workload-only operation rather than changing the management stack.

The current development gateway derives a PKI dependency from any explicit
workload, even with no declared exposure. This is another early decision seam,
not evidence that a workload inherently requires SQL or Identity.

Authoritative owners remain deployment Target roots/records, protected
application runtime files, capability registry instances/bindings and existing
provider state. No footprint registry or second lifecycle is introduced.
`prepareUndeclaredProviderCleanup` currently prepares obsolete metrics/logs
reconciliation after capability removal; retained/shared resources require
explicit examination before changing this behavior.

## Characterization and qualification

`app_coreless_characterization_test.go` proves workload-only runtime files need
no issuer, create no backend resource inventory or broker, reject changed
Compose definitions, and reject materialization without a workload. It also
pins the old unconditional up/Core and implicit gateway dependency until the
resolver handoff; replace that characterization with the new regression
expectation when wiring the API.

Baseline targeted Go tests pass with Go 1.26.0. Hugging Face Jobs returns
`UNAVAILABLE` (`hf_jobs not returned by tools/list`); no job was submitted.
No Docker/rootless Podman receipt exists yet.

Runtime qualification must wait for the integrated exact SHA and green fast
tests. Use isolated resources for: real no-Core workload; missing source;
SQL/Secrets/Identity/HTTPS individually; explicit management Core; shared/BYO
and two apps; missing/incompatible/foreign bindings; capability removal;
partial/corrupt runtime; stop/resume/destroy/repeated destroy; stable ID,
State-root and CLI/JSON/MCP parity. Record actual inventory and footprint
evidence, never estimated container counts presented as measurements.

Session 1 owns resolver/footprint API and identity convergence. Productive
wiring waits for its tested handoff SHA and shared-file agreement in PR #881.
No pre-release, merge, tag or release is authorized.
