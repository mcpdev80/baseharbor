## Architecture and compatibility

PASS:

- Manifest v1 remains the portable application contract.
- Development metadata is authoring-time metadata, not runtime/provider intent.
- Local workspace paths remain XDG-local and do not define Application/Component identity.
- Docker and Podman retain equivalent runtime semantic coverage.
- Kubernetes/OpenShift resource preflight explicitly requires future cluster/provider evidence; local CLI-host `/proc` evidence is not reused.
- Backstage integration is emitted-contract-only and introduces no portal runtime dependency.

## Dependency/toolchain decision

v0.4.18 retains:

```text
go 1.25.0
golang.org/x/crypto v0.55.0
```

Renovate #534 was explicitly deferred because x/crypto v0.56/v0.57 requires Go 1.26 and would silently change the supported compiler baseline.

The YAML v3 module migration to `go.yaml.in/yaml/v3` is included.

## Test architecture

Small acceptance gates remain individually runnable.

The release-wide runtime proof is sharded symmetrically:

```text
Docker · Core Journey
Docker · Operations
Podman · Core Journey
Podman · Operations
```

Real container/network/volume/health/TLS/lifecycle/ownership behavior is exercised on both runtimes. Provider-neutral parser/schema/planner/workspace contracts run once.

Capability-matrix contract cases avoid unnecessary runtime/provider startup. Runtime cases start only the providers required by the selected profile; the full demo remains the owner of full-stack capability verification.
