## Process exit codes

The `baha` process exits with a single integer status that encodes the outcome for shells, pipelines, and automation. The exit-code set is a stable public contract: the documented set and the behavior in `internal/cli/cli.go` (`ExitCode`) and `cmd/baha/main.go` are locked together and verified by a Go contract test plus a documentation-audit row.

| Code | Meaning | Origin |
| --- | --- | --- |
| `0` | Success | `ExitCode(nil)` returns `0` (`internal/cli/cli.go:114-117`) |
| `1` | Runtime failure | Unclassified command error falls through to `1` (`internal/cli/cli.go:126`) |
| `2` | Usage error | `*UsageError` maps to `2` (`internal/cli/cli.go:118-121`) |
| `130` | Interrupted (`SIGINT`) | `context.Canceled` from the interrupt resolves to 130 (`internal/cli/cli.go: ResolveProcessExitCode`); `os.Interrupt` handler resolves via `internal/cli/cli.go: SignalExitCode` |
| `143` | Terminated (`SIGTERM`) | `syscall.SIGTERM` handler (`internal/cli/cli.go: SignalExitCode`) |

Child status passthrough: `baha app exec` passes a child process status through unchanged. `internal/cli.WithExitCode` carries an explicit OS status in the `1-255` range through the command tree as an `*ExitCodeError`, and `ExitCode` returns that status (`internal/cli/cli.go:102-127`). Statuses outside `1-255` (including `0` and `>255`) are rejected by `WithExitCode` and fall back to the runtime-failure code `1`.

How the code is chosen: `main` runs the command tree and, on error, calls `cli.ResolveProcessExitCode(err)`. A `context.Canceled` error from an interrupt becomes `130` (this bypasses `cli.ExitCode`, which would map a bare `context.Canceled` to the runtime-failure code `1`); a `*UsageError` becomes `2`; a `WithExitCode`-tagged error becomes its carried status; everything else falls through to `cli.ExitCode(err)`, which returns `1`. The two signals the running handler registers (`os.Interrupt`, `syscall.SIGTERM`) resolve to `130`/`143` via `cli.SignalExitCode`. See the [outcome classes](errors.md) for how the semantic result maps onto these codes.
