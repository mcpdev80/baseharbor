# Version-matched Core, Console and Node Connector

BaseHarbor v0.4.24 integrates the task-oriented CLI, native provider recovery, optional Web Console and remote Node Connector. The code candidate has completed joint native Docker/Podman acceptance and full pre-release validation.

## Choose your workflow

- Start locally with [your first application](../tutorials/getting-started.md).
- For a Core VM, developer workstation and remote Podman host, follow the [homelab guide](../tutorials/homelab.md).
- Use [backup and restore](backup-restore.md) before supported provider changes; review [provider support boundaries](../explanation/providers.md).

Core provides mandatory SQL, Secrets and Identity. Console is a client of the protected Core API; the Node Connector supplies authenticated outbound transport for remote Docker/Podman Targets. Kubernetes/OpenShift use their native APIs.

## Keep components compatible

Use the tested code dependencies in the consumers' `integration-candidate.json` and the demo's `baseharbor-core.ref`. Documentation corrections do not change those immutable code pins. Source checks alone do not establish native runtime support.

The accepted workflows cover Core setup, application lifecycle, managed enrollment/reconnect/revocation, Console OIDC/RBAC, events, logs, terminal and credential/CA rotation. Cross-host failover, application-scoped PostgreSQL HA and unsupported provider upgrades are outside this release.

The [release notes](../releases/v0.4.24.md) summarize the developer highlights and compatibility changes.
