# BaseHarbor CI v1.0

This package uses the two supplied images as the canonical artwork. No mascot or logo redesign was performed.

## Contents
- `BaseHarbor-CI-Guide-v1.0.pdf` - complete CI guide
- `baseharbor-master-lockup.png` - original supplied master artwork
- `baseharbor-mascot-mark.png` - original supplied transparent mark
- `baseharbor-icon-*.png` - resized icon derivatives only
- `baseharbor.ico` - favicon bundle
- `brand-tokens.json` / `brand-tokens.css` - implementation tokens

## Core typography
- Inter for UI, docs and marketing
- JetBrains Mono for CLI/code
