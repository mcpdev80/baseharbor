# BaseHarbor v0.4.27

## Connect developer workstations to Core

Import a one-use workstation invitation and manage applications through a named Target. Workstations connect directly to Core over mTLS; Core-local Docker and Podman do not require a Node Connector.

## Manage users and workstations

Invite users through the configured identity provider and assign Target-scoped access profiles. Offboard users and list, renew or revoke each workstation independently.

## Track versions by deployment stage

Keep desired, applied and observed application versions separate for each stage. Inspect which release and component versions are requested and running.

## Apply Target deployment policies

Choose editable development, test, staging or production presets for a Target. Existing Targets keep their saved policy during upgrades. Policy editing is currently supported for Core-local Targets.

## Destroy a connected Core from the workstation

`baha destroy` can review and remove the installation behind one authenticated remote Target, verify Core cleanup, then remove the workstation's owned connection and trust state. Local Docker and Podman Targets remain supported.

## Complete application destruction

`baha app destroy` removes the selected application's BaseHarbor state when provider impact inventory is incomplete. Shared or unverified provider resources remain in place.

## Demo update

The guided Demo follows the exact-candidate confirmation flow and includes a companion application for testing explicit cross-application connectivity.
