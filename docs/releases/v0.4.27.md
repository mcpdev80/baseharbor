# BaseHarbor v0.4.27

## Develop locally, manage remotely

BaseHarbor brings local and remote application management closer together. The CLI uses one installation as the authority for application state and access decisions. A guided onboarding flow helps connect workstations and reuse trusted connections, while the optional Node Connector remains responsible for separate remote runtime hosts.

## Guided access for teams

- **Access wizard:** assign scoped access profiles to users and deliberately revoke access when someone leaves.
- **Managed users and SSO:** invite users through the configured identity provider and apply Target-scoped permissions.
- **Connection profiles:** import and export portable, non-secret connection settings. Eligible local credentials can be exported separately in an encrypted file.

## Application releases and environments

- **Stage-specific versions:** keep desired, deployed and observed application versions and configuration separate for each deployment environment.
- **Readable version status:** see which release and component images are requested, applied and running.
- **Artifact reuse:** resolve existing OCI images and release inputs rather than introducing a proprietary package format. Integrate with configured registries and native image transfer.
- **GitOps-friendly delivery:** preserve the external system's ownership of deployments instead of overriding its desired state.

## More resilient operations

Application identity is allocated and managed by the owning installation, so a fresh checkout can attach to an existing registered application. Persistent execution records, mutation locks and state-recovery handling make interrupted or concurrent operations safer. Error messages better distinguish unavailable services, permission failures and foreign resources.

## Compatibility

Docker/Compose and rootless Podman/Quadlet remain the main local runtime paths. Demo, Console and Node Connector are independent, compatible components; Kubernetes/OpenShift runtime support is not newly promised by this release.
