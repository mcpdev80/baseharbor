# BaseHarbor v0.4.27

## Develop locally, deploy remotely

Connect a developer workstation to a BaseHarbor Core on another machine using guided onboarding. The workstation talks directly to Core; Node Connector remains optional for separate remote runtime hosts.

## Safer deployment defaults

Editable Target policies provide suitable defaults for development, test, staging and production. Teams control allowed branches, clean working trees, verified commits, approvals and image digests.

## More reliable application management

Application registration and lifecycle operations handle concurrent commands and interrupted runs more safely. Clearer diagnostics distinguish permission errors, unavailable resources and foreign installations.

## Compatibility

Docker/Compose and rootless Podman/Quadlet remain the primary local runtimes. The Demo, Console and Node Connector are separately versioned integrations. Existing CI/CD, registries and GitOps tools stay in control of their respective workflows.
