# BaseHarbor v0.4.24

Build apps with fewer setup steps, keep operations on the right Target, and recover managed services with clearer safeguards.

## Highlights

- **A simpler path from a new project to a running app.** Start with `baha new`, select a Core or Target with `baha use`, and run application commands from your repository. Repository-aware `baha down` and `baha destroy` resolve the application context; guided setup helps when a Core is needed.
- **Rootless Docker by default, with predictable Target routing.** CLI and MCP operations stay bound to the selected runtime endpoint, even when your ambient Docker context changes. Status and Doctor show the actual socket and runtime mode; remote selections never silently fall back to your local Core.
- **Shared services without duplicate provider servers.** Shared Keycloak and application SQL use Core PostgreSQL with separate databases and users. Shared Valkey isolates applications with ACL users and key namespaces. HA is opt-in, so a standard installation avoids unnecessary replicas.
- **Stronger backup and recovery for managed providers.** Native PostgreSQL physical backup/WAL recovery and authenticated etcd snapshot recovery support the shared HA recovery path on Docker and Podman. Provider updates check pinned images, ownership, compatible versions and verified backups before proceeding.
- **More useful diagnostics and safer cleanup.** Readiness reflects live checks, occupied-port fallback requires consent and reports the chosen port, and stopped development routes give actionable guidance. Cleanup preserves foreign resources and retained data; Core rebootstrap preserves existing recovery backups.

## Compatibility notes

- Use `baha app sql` and `baha app cache` for application SQL and cache operations, replacing the older `app psql` and `app valkey` names.
- Existing installations are not silently converted to a new topology. PostgreSQL major-version upgrades, application-scoped PostgreSQL HA and cross-host failover remain unsupported. Recovery does not automatically replay SQL transactions whose commit outcome is unknown.
