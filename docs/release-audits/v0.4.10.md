## Security review

Tempo is rendered with:

- explicit non-root UID/GID;
- read-only root filesystem;
- `cap_drop: ALL`;
- `no-new-privileges`;
- explicit writable persistent volume and tmpfs only;
- host API bound to loopback.

Provider signal collection creates only collector-to-provider reachability. It does not put applications on provider observability networks.

Provider registrations contain provider/source identity, network target and metrics path only. They contain no password, token, private key or credential-bearing URL.

## Compatibility

Manifest v1 is unchanged. Existing PostgreSQL, Valkey, OpenBao, Caddy, S3, OTLP, Prometheus, Loki/Alloy and Runtime Resource API behavior remains compatible.

Managed trace storage is deployment policy and is disabled unless explicitly enabled. Requesting OTLP transport alone does not provision Tempo.
