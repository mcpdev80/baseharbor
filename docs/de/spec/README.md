# BaseHarbor-Spezifikationen

Dieses Verzeichnis enthält normative öffentliche Verträge und verbindliche Invarianten.

Benutzeranleitungen erklären die Verwendung von BaseHarbor. Spezifikationen legen fest, welche Garantien Implementierungen erfüllen müssen.

Die BCP-14-Begriffe MUST, MUST NOT, SHOULD und MAY werden nur dort verwendet, wo Interoperabilität, Kompatibilität oder Sicherheit dies verlangen.

Wo sinnvoll, sind maschinenlesbare Definitionen maßgeblich:

- JSON Schema und typisierte Schemas für Manifeste und Deskriptoren;
- OpenAPI für REST-Schnittstellen;
- Protocol Buffers für externe Provider-Prozessgrenzen;
- typisierte Maschinen-Ergebnis- und Fehlerschemas;
- ausführbare Conformance-Fixtures.
