## Annahmevorschriften

- Die Anmeldeinformationen für Maschinen der Klasse C werden niemals durch freigegebene Entwickler-/Human-Anmeldeinformationen ersetzt.
- Anwender/Rollen von Anwendungen sind in dieser Matrix nicht vertreten.
- Eine Bewirtschaftungsfläche darf nur Anspruch auf `native-oidc`, ` standards-auth-adapter `, ` native-credential ` or ` unsupported`.
- Role Mappings sind exakt, begrenzt oder nicht unterstützt; kein Anbieter wird mit einer feineren Autorisierung gutgeschrieben, als es durchsetzt.
- Geheime autoritative Host State bleibt Eigentümer-only. Breitere Laufzeit Lesbarkeit ist eine separate Lese-only-Projektion.
- Effektive HA-Anfragen gegen jede aktuelle UNSUPPORTED-Reihe scheitern vor der Mutation.
- Ein zukünftiger Anbieter kann nur seine Realisierung/Klassifizierung ändern, nicht den portablen Anwendungsvertrag.
