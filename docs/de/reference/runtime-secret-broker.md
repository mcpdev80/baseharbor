# Runtime Secret Broker

Diese Seite beschreibt die frühere Bezeichnung einer Runtime-Komponente pro Application.

Die Komponente heißt jetzt **Application Runtime Broker**, da verwaltete Secrets nur eine von mehreren Runtime-Fähigkeiten sind. Der Broker definiert außerdem die Architekturgrenze für Runtime-Ressourcen, asynchrone Operationen und zukünftige Application-Funktionen zur Laufzeit.

Siehe [Application Runtime Broker](../spec/application-runtime-broker.md) für den aktuellen Vertrag.

Bestehende Secret-Endpunkte und das Verhalten der Runtime-Identität bleiben kompatibel.
