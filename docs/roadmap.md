# Roadmap

Detailed planning lives in GitHub Issues. This page only shows product direction.

## Current

### v0.4

Complete the portable BaseHarbor core:

- lifecycle and reconciliation;
- audit/evidence;
- provider SDK/conformance;
- managed application identity;
- full-stack pre-freeze acceptance.

## Next

### v0.5

Freeze, version and harden the public contracts.

No new major platform primitive belongs in the v0.5 line.

## Then

### v0.6

Portable availability and guarantee semantics.

### v0.7

Kubernetes Runtime implementation.

### v0.8

Kubernetes Complete: lifecycle, capabilities, recovery, observability, agent parity and production hardening.

## Later

OpenShift, enterprise and cloud/runtime expansion build on the frozen portable contracts.

Optional ecosystem integrations such as additional visual tooling, messaging, AI and vector/RAG capabilities remain separate from core contract completion.
