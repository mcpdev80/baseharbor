# messaging.queue/v1

`messaging.queue/v1` describes point-to-point queued message delivery.

## Required semantics

- Stable logical queue resource identity independent of broker topology.
- Application-scoped connection credentials and trust.
- Provider-specific exchanges, vhosts, bindings and routing internals stay outside portable intent.
- READY requires publish -> consume -> acknowledge verification through the application-facing binding.
- Durable provider history is not claimed recoverable unless recovery support is explicitly implemented and verified.
- AsyncAPI may describe the application messaging API; AMQP or another broker protocol is provider compatibility, not service identity.

## Reference provider

BaseHarbor's current reference implementation is RabbitMQ.
