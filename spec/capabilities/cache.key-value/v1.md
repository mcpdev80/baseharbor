# cache.key-value/v1

A provider implementing `cache.key-value/v1` supplies an application-owned logical Redis-compatible key/value resource.

## Required semantics

- Stable logical resource identity per application/name.
- Provider-specific instance/container/object identity remains deployment state.
- Application-scoped access credentials or credential references where authentication is supported.
- Redis-compatible application connectivity for the current v1 contract.
- Cross-application access denied by default.
- Preflight must complete before provisioning mutation.
- Successful verification requires a real authenticated protocol probe such as PING/PONG.
- Destructive lifecycle operations must respect provider scope and lifecycle ownership.

## Reference provider

BaseHarbor's current reference implementation is Valkey.
