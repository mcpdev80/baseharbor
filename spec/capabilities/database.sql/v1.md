# database.sql/v1

A provider implementing `database.sql/v1` supplies an application-owned logical SQL database resource.

## Required semantics

- Stable logical resource identity per application/name.
- Provider-specific database/object names remain deployment state.
- Application-specific credentials or credential references.
- Standard SQL connectivity information suitable for native application clients.
- Cross-application access denied by default.
- Preflight must complete before provisioning mutation.
- Successful verification requires a real authenticated query; configuration presence alone is insufficient.
- Destructive lifecycle operations must respect provider scope and lifecycle ownership.

## Binding expectations

The provider/binding layer must be able to expose standard connection information without placing secret values in portable application intent or normal diagnostics.

## Reference provider

BaseHarbor's current reference implementation is PostgreSQL.
