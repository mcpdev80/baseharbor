# database.document/v1

`database.document/v1` describes durable application-owned document storage without exposing a concrete document-database product.

## Required semantics

- Stable logical database/resource identity independent of provider topology.
- Application-scoped least-privilege credentials.
- Durable document read/write semantics.
- Successful readiness requires an authenticated write/read/delete verification through the application-facing path.
- Required index/transaction semantics may be declared only when they represent demonstrated portable application requirements.
- Backup/recovery support is explicit; unsupported recovery must remain visible in evidence.
- Provider topology, storage engines, replica-set names and administration internals remain provider state.
- Destroy and reconciliation preserve application/shared/external ownership boundaries.

## Reference provider

BaseHarbor's current reference implementation is MongoDB.
