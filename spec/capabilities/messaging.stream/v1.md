# messaging.stream/v1

`messaging.stream/v1` describes ordered stream append and replay/advance semantics.

## Required semantics

- Stable logical stream identity independent of broker topology.
- Application-scoped connection credentials and trust.
- READY requires append -> consume/replay -> advance verification.
- Retention, partitioning and broker-specific topology remain provider state unless a portable semantic is explicitly standardized.
- Message-history recovery is not implied by service readiness.
- AsyncAPI/CloudEvents are used where applicable; broker protocol remains a provider compatibility property.

## Reference provider

BaseHarbor's current reference implementation is RabbitMQ.
