# secrets/v1

A provider implementing `secrets/v1` supplies application-isolated secret storage and retrieval semantics.

## Required semantics

- Secret values never enter portable application intent.
- Secret values never appear in normal diagnostics, logs, status payloads or provider registry state.
- Application/workload isolation is enforced at the authoritative provider boundary.
- Bindings use stable secret or credential references where possible.
- Preflight validates provider reachability and required security prerequisites before mutation.
- Verification proves application-scoped authenticated access rather than process liveness alone.
- Destroy/release must not remove shared provider infrastructure merely because one application binding is removed.

## Reference provider

BaseHarbor's current reference implementation is OpenBao.
