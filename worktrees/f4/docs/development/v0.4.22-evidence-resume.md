# v0.4.22 evidence resume

Status: candidate implementation; final runtime approval remains pending.

All 55 acceptance proofs remain required. Source checks and the candidate build
always run for the new candidate. Completed child jobs from a cancelled run can
be reused only when their own outcome and cleanup passed. Cancelled jobs never
count as successful evidence.

Reuse compares immutable Git objects for product, build, test and declared runner
inputs. Original manifests keep their candidate, demo pin, run and attempt; the
coverage receipt binds equivalent inputs to the new candidate without rewriting
the original evidence. Shared helpers or product changes invalidate affected
proofs. A newer compatible failure prevents fallback to an older success.

The MCP snapshot correction is a narrowly reviewed dependency exception:
`tests/mcp/run.sh` affects the static MCP gate and both complete journeys. Every
other demo file remains an input for every gate. This conservative rule does not
assume that arbitrary test directories are independent.

Artifacts must belong to a trusted push workflow in this repository, match an
exact completed child job and attempt, and pass archive digest, manifest, schema,
identity and cleanup validation. Missing, expired or incompatible evidence is
reported as pending and scheduled again. Trusted targeted proof runs are retained
by repository GC alongside prerelease and release runs. Runner declarations are compared; this
is not a claim that hosted runner images or measured memory are identical.

Public GitHub Pages deployment happens after the documentation reaches `main`.
PR source builds validate the English and German sites but do not publish them.
