# identity.oidc/v1

`identity.oidc/v1` describes standards-based application identity using OpenID Connect and OAuth 2.0 semantics.

## Required semantics

- Standard issuer discovery and JWKS semantics.
- Application client identity, redirect/logout paths, scopes and claims remain provider-neutral.
- Authentication policy such as MFA/passkey/passwordless requirements is expressed semantically, not as provider administration commands.
- Application bindings expose issuer/client/trust material without provider-admin credentials.
- Managed and external identity providers satisfy the same application-facing contract.
- Provider realm/tenant topology and administration endpoints remain deployment/provider state.

## Reference providers

BaseHarbor currently supports managed Keycloak and external OIDC realizations.
