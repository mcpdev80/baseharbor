Ein neuerer kompatibler Fehler verhindert Rückfall zu einem älteren Erfolg.

Die MCP-Snapshot-Korrektur ist eine eng überarbeitete Abhängigkeits-Ausnahme:
`tests/mcp/run.sh` beeinflusst das statische MCP-Tor und beide komplette Fahrten.
andere Demo-Datei bleibt eine Eingabe für jedes Gate. Diese konservative Regel nicht
davon ausgehen, dass beliebige Testverzeichnisse unabhängig sind.

Artefakte müssen zu einem vertrauenswürdigen Push-Workflow in diesem Repository gehören, mit einem
exakt abgeschlossene Kind Job und Versuch, und übergeben Archiv verdauen, manifest, Schema,
Identitäts- und Aufräumvalidierung. Fehlende, abgelaufene oder unvereinbare Beweise sind
als anstehend und wieder planmäßig gemeldet. Trusted Targeted Proof Runs werden beibehalten
durch das Repository GC neben Prelease- und Release-Runs. Runner-Deklarationen werden verglichen; dies
ist keine Behauptung, dass gehostete Läuferbilder oder gemessener Speicher identisch sind.

Öffentliche GitHub Pages-Bereitstellung erfolgt, nachdem die Dokumentation erreicht `main`.
PR Source Builds bestätigen die englischen und deutschen Seiten, veröffentlichen sie aber nicht.
