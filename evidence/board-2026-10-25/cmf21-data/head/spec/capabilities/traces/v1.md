# traces/v1

## Purpose

`traces/v1` is BaseHarbor's provider-neutral trace-storage platform contract. Applications do not request Tempo, Jaeger or another trace product by name.

Application instrumentation and transport remain expressed through `telemetry.otlp/v1`. Deployment policy decides whether exported trace signals are retained and which trace provider satisfies that platform function.

## Semantics

- accepts OTLP trace data through a provider-managed ingestion path;
- preserves BaseHarbor application/environment/resource identity;
- storage topology and retention remain provider/operator state;
- provider-internal object storage is not exposed as an application S3 binding;
- successful verification proves that a trace can be queried after ingestion.

## Placement

Providers may support `shared`, `application` and/or `external` placement through the generic provider-placement model.

Shared placement does not grant applications direct access to the trace backend.

## Non-goals

This capability does not imply:

- Grafana;
- Prometheus;
- Loki;
- application access to provider-internal storage;
- a specific trace backend product.
